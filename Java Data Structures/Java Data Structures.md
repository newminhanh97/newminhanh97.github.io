# Java Data Structures

Data structures are ways to store and organize data. Java includes many other data structures as well, in the `java.util` package. Each is used to handle data in different ways.
Some of the most common are:
- **ArrayList:** is a **resizable array**, allows to store elements and access them by **index**
- **HashSet:** is a collection where every element is **unique** - no duplicates.
- **HashMap:** stores **key-value pairs**, to store values and find them by a key.

**Data Structures Overview**

| Data Structure | Stores | Keeps Order? | Allows Duplicates? | Best For |
| --- | --- | --- | --- | --- |
| ArrayList | Ordered elements | Yes | Yes | Accessing elements by index |
| HashSet | Unique elements | No | No | Avoiding duplicates, fast checks |
| HashMap | Key-value pairs | No | Yes (keys are unique) | Fast lookup by key |
