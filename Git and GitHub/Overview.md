Git records changes to files so you can review history, work on separate ideas, and combine them later. GitHub hosts Git repositories online and adds collaboration tools such as issues, pull requests, and automated workflows.

## Learning path

1. [[Git Basics]] - Track changes and work with commits and branches.
2. [[GitHub Workflow]] - Collaborate using repositories, issues, and pull requests.
3. [[GitHub Actions]] - Automate checks and tasks with workflow files.

## Git and GitHub

Git is the version control program running on your computer. GitHub is a service that stores a remote copy of a repository and makes it easier to collaborate. You can use Git without GitHub, and GitHub repositories use Git to track their history.
